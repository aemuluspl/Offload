# Offload (Mind Note)

Приложение для быстрого захвата мыслей: записал за пару секунд — и оно больше не
занимает рабочую память.

**Работает полностью на телефоне.** Ни сервера, ни компьютера, ни облака: все
заметки лежат в приватной папке приложения на устройстве. Интернет не нужен для
работы с заметками — он используется только для добровольной проверки обновлений.

## Что умеет

- Быстрый ввод мысли: в покое только микрофон, при наборе появляется отправка.
- Редактирование текста, отметка «сделано», удаление.
- Поиск по тексту и фильтр по `#хэштегам`.
- Плоский 2D-граф связей по тегам с физикой и таймлапсом истории заметок.
- Строгий монохром: белый акцент в тёмной теме, чёрный — в светлой.
- Кастомизация: единый радиус скруглений 4–40 px и «глубокий чёрный» фон.
- Настройки размера узлов графа и скорости анимации панели.
- Данные сохраняются сразу и не теряются при перезапуске.
- Обновления «по воздуху»: проверка релиза на GitHub и установка APK поверх
  старой версии (заметки сохраняются).

## Стек

| Часть | Технология |
|---|---|
| Язык | Dart |
| Фреймворк | Flutter (только Android — телефон и планшет) |
| Хранилище | JSON-файл в приватном каталоге приложения |
| Сборка APK | Gradle + Android SDK |

Почему не SQLite: личных заметок тысячи, а не миллионы; JSON не тянет нативных
зависимостей, легко резервируется копированием и пишется атомарно (временный
файл + переименование). Если появятся тяжёлые запросы или полнотекстовый поиск,
хранилище меняется за одним интерфейсом `NoteStore`.

## Где лежат данные

`<приватная папка приложения>/offload/notes.json` — на Android это внутреннее
хранилище приложения, недоступное другим программам без root. Файл создаётся
при первой заметке.

Важно: удаление приложения удаляет и заметки. Экспорт/импорт и резервная копия —
в плане развития (`docs/ROADMAP.md`).

## Обновления

Настройки → «Обновления» → «Скачать». Приложение спросит GitHub о последнем
релизе, скачает APK и откроет системный установщик. Android всегда показывает
подтверждение — тихая установка сторонних APK запрещена.

- Проверка выполняется только по нажатию; в фоне приложение в сеть не ходит.
- Новый APK ставится поверх старого, заметки сохраняются. Для этого все релизы
  одной ветки подписываются одним ключом (`app/android/offload-release.jks`).
- Начиная с 1.0.2 используется новый ключ подписи: установка поверх 1.0.1
  невозможна, старую версию нужно удалить и поставить 1.0.2 начисто.
- Репозиторий задаётся в `app/lib/update_config.dart` (сейчас
  `aemuluspl/Offload`) или при сборке:
  `--dart-define=UPDATE_REPO=владелец/репозиторий`.
- Репозиторий должен быть публичным: приложение читает релизы без токена.
- В релизе должен лежать ровно один APK-файл: имя заканчивается на `.apk`.

Пошаговая публикация релиза — в [`docs/ANDROID_APK.md`](docs/ANDROID_APK.md).

## Ограничения

- Голосовой ввод пока не подключён: системное распознавание речи Android может
  требовать интернет и сервисы Google. Локальная альтернатива — клавиатура
  телефона (например, Gboard) с офлайн-диктовкой.
- Напоминаний и уведомлений нет — это следующий плагин.
- Интерфейс рассчитан на телефон; на широком экране показывается в рамке.
- Обновления требуют интернета и публичного GitHub-репозитория. Без них
  приложение продолжает работать, просто не проверяет новые версии.

## История

Проект начинался как микроядерный сервер (FastAPI + SQLite + плагины) с
Flutter-клиентом. Серверную часть заменило локальное хранилище на устройстве;
старая версия сохранена в git-теге `v0.2-server`.
