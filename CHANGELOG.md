## 2026-10-28 — Offload 1.0.4: установка на vivo/iQOO и проверка APK

- **Установка:** обновление теперь ставится через системный `PackageInstaller`,
  а не через `ACTION_VIEW`. На vivo/iQOO это обходит V-Appstore, который
  перехватывал APK и показывал «APK damaged» с рекламой своего магазина
  (`MainActivity.kt`, `AndroidManifest.xml`).
- **Проверка файла:** SHA-256 скачанного APK сверяется с digest из GitHub
  Release; повреждённый файл не передаётся установщику (`update_service.dart`).
- **Подпись:** включены схемы V1 + V2 + V3 с тем же сертификатом — для
  совместимости с OEM-установщиками.
- **Версия:** `1.0.4+5`.

## 2026-10-28 — Offload 1.0.3: Liquid UI и кастомизация

- **Иконка:** в APK вшита новая иконка «три вертикальных овала»: legacy,
  круглая и adaptive-версии для всех плотностей (`mipmap-*`, `colors.xml`).
- **Анимация:** центральная кнопка навбара с иконкой графа снова плавно
  поворачивается на 360° при каждом нажатии (`offload_nav_bar.dart`).
- **Liquid UI:** все карточки, поля, кнопки, плашки и диалоги используют общий
  радиус скруглений вместо «квадратных» значений 8–18 px.
- **Кастомизация:** в настройках появился блок «Кастомизация интерфейса»:
  ползунок радиуса (4–40 px) и переключатель «Глубокий чёрный» (фон #000000).
  Изменения применяются в реальном времени и сохраняются в настройках
  (`app_settings.dart`, `settings_store.dart`, `settings_panel.dart`).
- **Версия:** `1.0.3+4`.

## 2026-10-28 — Offload 1.0.2: монохром, 2D-граф, новый композер

- **Монохром:** зелёный акцент убран полностью. В тёмной теме акцент белый, в
  светлой — чёрный; заметки нейтрально-серые, выбор цвета удалён
  (`offload_theme.dart`, `note.dart`, `settings_panel.dart`).
- **Композер:** в покое справа только микрофон. При вводе текста появляется
  кнопка отправки, а микрофон плавно отодвигается левее с morph-анимацией.
  «Плюс» заменён стрелкой отправки (`home_screen.dart`).
- **Граф:** 3D-орб переписан в плоский 2D force-directed граф с притяжением,
  отталкиванием, зумом, перетаскиванием узлов и кнопкой таймлапса истории
  создания заметок (`graph_orb.dart`).
- **Геометрия:** уменьшены скругления карточек, меню, поиска, композера и
  навбара; нижняя панель выровнена по центру, тени переработаны; иконка графа
  стала плоской (`offload_nav_bar.dart`).
- **Настройки:** убраны цвет заметок, время жизни капли и полноэкранный режим.
  Капля фиксирована на 3 секунды; остались размер узлов, скорость анимации,
  состояние хранилища и проверка обновлений.
- **Подпись:** сгенерирован новый ключ RSA 4096 / SHA-256. Установка 1.0.2
  поверх 1.0.1 невозможна — нужна чистая установка. Резервный архив:
  `Offload-signing-key-20261028-1.0.2.zip`.
- **Версия:** `1.0.2+3`.

## 2026-10-27 — Переход на полностью локальное Android-приложение

- **Архитектура:** Python-сервер (FastAPI + SQLite + плагины) удалён из рабочей
  ветки. Старая версия доступна в git-теге `v0.2-server`.
- **Хранилище:** заметки теперь в JSON-файле в приватной папке приложения
  (`app/lib/data/json_note_store.dart`). Ни сети, ни компьютера не требуется.
- **Клиент:** `ApiClient` и `config.dart` удалены; экран работает с локальным
  хранилищем. Индикатор «сервер онлайн» заменён на состояние данных.
- **Android:** из манифеста убраны разрешение `INTERNET` и `usesCleartextTraffic`.
- **Структура:** `frontend/` → `app/`, HTML-макет → `docs/reference/`,
  скрипты и лаунчеры удалены (не нужны без сервера).
- **Тесты:** 11 тестов на модель, хэштеги и хранилище (было 3).
- **Документация:** README, `docs/ANDROID_APK.md`, `docs/ROADMAP.md` переписаны
  под локальное приложение.
- **Только Android:** удалены `app/web/`, зависимость `web` и ветка `kIsWeb`
  в хранилище. Полноэкранный режим переведён на `SystemChrome` (Android),
  файлы `fullscreen_web.dart` и `fullscreen_stub.dart` удалены.
- **Обновления:** в настройках появился экран проверки релизов GitHub.
  Приложение скачивает APK и открывает системный установщик; данные сохраняются.
  Сеть используется только по нажатию кнопки. Версия `1.0.1+2`.
