# План развития

Принципы:

1. **Всё локально.** Ни сервера, ни аккаунтов, ни облака. Приложение обязано
   работать в самолёте и без компьютера.
2. **Скорость захвата важнее функций.** Мысль записывается за 2–3 секунды.
3. **Данные принадлежат человеку.** Файл заметок должен легко копироваться и
   восстанавливаться.
4. **Не тащить зависимости без нужды.** Каждая библиотека — это риск сборки.

## Сделано

- Полностью локальное приложение: JSON-хранилище в приватной папке.
- Заметки: создание, редактирование, «сделано», удаление.
- Поиск, `#хэштеги`, плоский 2D-граф связей с таймлапсом, монохромные темы.
- Liquid UI и кастомизация: общий радиус скруглений и «глубокий чёрный».
- 16 тестов на модель, хэштеги, хранилище и версии.
- Android-проект с `INTERNET` только для добровольной проверки обновлений.

## Приоритет 1 — надёжность данных

- **Экспорт и импорт**: сохранить `notes.json` в «Загрузки» и загрузить обратно.
  Без этого удаление приложения = потеря заметок. Самая важная функция.
- Автоматическая резервная копия при запуске (последние 3 версии файла).
- Понятный экран ошибки, если файл повреждён, с предложением восстановить копию.

## Приоритет 2 — ежедневное удобство

- **Отмена удаления** (SnackBar «Вернуть») вместо мгновенного удаления.
- **Время создания на карточке** — `Note.createdAtLabel` уже написан.
- **Автодополнение тегов** при вводе `#`.
- **Свайпы**: вправо — выполнено, влево — удалить.
- **Архив выполненных**, чтобы список не разрастался.
- Заменить заглушки «Аналитика» и «Динамика» на реальные экраны:
  «Теги» (облако тегов) и «Сегодня» (сводка дня).

## Приоритет 3 — возможности телефона

- **Напоминания**: локальные уведомления (`flutter_local_notifications`)
  работают без интернета. Нужен `due_at` у заметки и планировщик.
- **Поделиться в Offload**: intent-filter на текст — заметка из любого
  приложения. Работает офлайн.
- **Голосовой ввод**: системное распознавание речи Android. На части устройств
  требует интернет и сервисы Google; полностью локальная альтернатива —
  клавиатура с офлайн-диктовкой или распознавание на устройстве (Whisper-модель,
  тяжело: 40–150 МБ и медленно на слабых телефонах).
- **Виджет на главный экран** — быстрый ввод без открытия приложения.

## Приоритет 4 — архитектура

- Несколько хранилищ (заметки, напоминания) за общим интерфейсом.
- Полнотекстовый поиск, если заметок станет больше ~5 тысяч.
- Миграции формата: поле `version` в файле уже есть, добавить обработку старых
  версий.
- Индексная схема `lib/data/<feature>_store.dart` как замена серверным плагинам.

## Чего не делаем

- Сервер, синхронизация, аккаунты, облако — противоречит требованию локальности.
- Копирование HTML-макета один в один: он остаётся референсом. Маскот-шмель не
  переносится; визуальный знак — орб из `graph_orb.dart`.
- Переписывание на Kotlin: Flutter уже работает и собирается в APK.
